Difficulty 7/10Core

Goal: Understand the advantage of Windows Authentication (Integrated Security) over plain SQL Authentication for MS SQL Server.

Where to look, not what to write
  • Set up SonarQube against an MS SQL Server database using Integrated Security (following the instructions specifically called out in sonar.properties for this mode).

  • Note the practical advantage: no plaintext SQL credential stored in a config file at all, authentication is delegated to the Windows account already running the SonarQube service.
