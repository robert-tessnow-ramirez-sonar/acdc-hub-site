AC/DC · Solve

Onboard AI CodeFix

Turn a flagged issue into a one-click, LLM-generated fix suggestion, reviewed and applied by the developer, directly in the Issues page or the IDE.

Cloud Team/Enterprise · Server Enterprise/Data CenterGenerally available on both platforms. Enabled per organization (Cloud) or per instance (Server) by an admin.

What the feature delivers

AI CodeFix covers the Solve stage for a single issue at a time, on demand, rather than a scheduled or batch workflow.

1

Suggests a fix on request

A developer clicks "Generate AI Fix" on an eligible issue. The affected code and issue description are sent to the configured LLM.

2

Applies or declines, developer's call

The proposed edit appears in the code editor. Nothing changes until the developer chooses Apply; Decline discards it with no side effects.

3

Works in the UI and the IDE

Available from the Issues page, and from SonarQube for VS Code or IntelliJ in connected mode, using the same quality profile rules.

Readiness checklist

Confirm these gates before enabling the feature. Cloud and Server share the shape of the checklist, but the specifics differ.

Eligible plan or editionCloud: Team (annual) or Enterprise plan. Server: Enterprise or Data Center edition only, not Community or Developer.
Admin accessCloud: an Organization Admin enables it under AI capabilities. Server: an Instance Admin enables it under General Settings.
LLM decision madeCloud is Sonar-hosted only (Claude Sonnet 4 or GPT-5.1). Server can use Sonar-hosted OpenAI or bring your own: Azure OpenAI, AWS Bedrock, or a self-hosted gateway.
Network path confirmedSonar-hosted LLM needs outbound HTTPS to api.sonarqube.io. A self-hosted or BYO-LLM path needs the instance to reach that specific endpoint instead.
Supported languageJava, JavaScript, TypeScript, Python, HTML, CSS, C#, or C++, and the issue's rule is on the AI CodeFix-eligible list.
Connected mode, if using the IDESonarQube for VS Code or IntelliJ must be bound to the same Cloud organization or Server instance to surface fixes inline.

Enable and run

The sequence is the same shape on both platforms; the settings location and LLM options differ.

01Enable the feature

Cloud: Your Organization > Administration > AI capabilities > AI CodeFix > Enable AI CodeFix. Server: Administration > Configuration > General Settings > AI CodeFix > Enable AI CodeFix.

02Choose the LLM provider

Cloud: pick Claude Sonnet 4 (recommended) or GPT-5.1. Server: pick Sonar's hosted OpenAI model, or configure Azure OpenAI, AWS Bedrock, or a self-hosted gateway with its endpoint and credentials.

03Scope to projects

Select All projects, or Only selected projects and add them individually. New projects are not added automatically under the selected-projects mode.

04Generate a fix

From an eligible issue, select Generate AI Fix in the Issues page, or the AI CodeFix tab on the rule description in a connected IDE, then Apply or Decline the suggestion.

Scope limitsOnly a select set of rules per language is eligible, review the Rules for AI CodeFix list before promising coverage. Usage against Sonar-hosted models is capped by a monthly quota per organization or instance, reset on the first of the month; self-hosted LLMs are not capped by Sonar but may hit the provider's own rate limits.

How a suggestion reaches a developer

Nothing lands in the codebase without a deliberate Apply.

1. DetectAnalysis flags an eligible issue on a supported language and rule.
→
2. RequestA developer selects Generate AI Fix from the Issues page or the IDE rule description.
→
3. GenerateThe affected code and issue description go to the configured LLM, which proposes an edit.
→
4. Apply or declineThe developer reviews the suggestion in the editor and chooses to apply it or discard it.

Definition of a successful onboarding

Enabled and scoped

The feature is on for the intended projects, and the admin has made a deliberate LLM choice rather than leaving a default.

Flowing to developers

Generate AI Fix appears on eligible issues in the UI and, where connected mode is set up, in the IDE.

Terms and data flow understood

Admins know where code goes for the chosen provider, and have reviewed the AI CodeFix terms before rollout.
