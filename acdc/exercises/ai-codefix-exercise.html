What's the difference between AI CodeFix, Sonar Vortex agentic analysis, the Remediation Agent, and Vortex context augmentation?

QuestionCore

Goal: Understand the differences between Sonar's AI features so you can point a customer to the right one.

Where to look, not what to write
  • Start with this repo's own onboarding pages: AI CodeFix, Vortex, Remediation Agent. Each has a "What the feature delivers" section — read all three back to back.
  • For each feature, ask yourself: which stage of the Agent Centric Development Cycle does it sit in (Guide, Verify, or Solve)? Is it triggered on demand, or does it run automatically?
  • Sonar docs: AI CodeFix, Sonar Vortex, Remediation Agent.

Why do you need to allow communication to the AI CodeFix service if you have a locally hosted LLM?

QuestionCore

Goal: Understand the architectural requirement behind this, not just recite it.

Where to look, not what to write
  • This is a genuinely subtle point — even the source catalog for this exercise flags it as needing further review. Don't assume the first explanation you find is complete.
  • Start from the Server requirements: "Network path confirmed" on the AI CodeFix onboarding page and the AI CodeFix row on Cloud & Server requirements.
  • Ask: even with a self-hosted or BYO-LLM, is there anything else in the AI CodeFix flow (licensing checks, rule metadata, telemetry, orchestration) that might still call out to a Sonar-hosted endpoint?
  • If you can't fully resolve this from docs alone, that's expected — note your best current understanding and flag your remaining question. This is a good one to raise with a mentor.

What causes a certificate error when connecting to the AI CodeFix service?

QuestionCore

Goal: Be able to troubleshoot a TLS/certificate error report from a customer.

Where to look, not what to write
  • Think generally about what causes TLS certificate errors in enterprise network setups: self-signed certs, internal CAs, proxies that intercept HTTPS, expired certs, hostname mismatches.
  • Cross-reference against the AI CodeFix network requirement (outbound HTTPS to a fixed endpoint) — what's on the customer's network path between their SonarQube instance and that endpoint?
  • This same class of problem shows up with the SonarQube MCP server and private certificates — if you get to that section later, compare notes.

8

Set up a self-hosted model for AI CodeFix

TaskStretch

Goal: Learn how to integrate a non-Sonar-hosted LLM into AI CodeFix. Optional, but worth attempting.

Where to look, not what to write
  • This one is marked optional in the source catalog — a cloud-hosted model you configure yourself counts. Bonus points if it's set up in Azure.
  • AI CodeFix on Server supports bring-your-own-LLM: Azure OpenAI, AWS Bedrock, or a self-hosted OpenAI-compatible gateway. Check the Server BYO-LLM options on the AI CodeFix onboarding page and Cloud & Server requirements.
  • If you don't have Server admin access to actually configure this, write up the steps you'd take and what credentials/endpoint info you'd need, and note that as a limitation.
